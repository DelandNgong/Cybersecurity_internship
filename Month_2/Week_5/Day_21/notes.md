Day 21: Introduction to Vulnerability Assessment

1. What is Vulnerability Assessment?
A systematic security process to identify, classify, and prioritize weaknesses in systems, networks, or applications before attackers can exploit them. Can be performed manually or using automated tools.

2. Key Benefits
- Provides thorough assessment of security standards
- Identifies security flaws proactively
- Helps implement security measures before attacks occur
- Reveals strengths and weaknesses of systems
- Supports compliance with security regulations
- Enables informed decision-making for security investments

3. Vulnerability Assessment vs Penetration Testing (VAPT)
Vulnerability Assessment focuses on scanning networks, systems, or software to identify as many flaws as possible through automated scanning and manual verification.

Penetration Testing takes an offensive approach by actually exploiting identified vulnerabilities to understand the real-world impact and attack paths. Performed by ethical hackers with proper authorization in controlled environments.

4. Common Scanning Tools
- Nmap: Network discovery and security auditing tool that sends packets and analyzes replies to find network vulnerabilities
- Wireshark: Network protocol analyzer for monitoring traffic and identifying suspicious activity
- OpenVAS: Open-source vulnerability scanner for comprehensive vulnerability detection
- Burp Suite: Web application security testing platform
- Qualys: Cloud-based vulnerability management platform
- Nessus: Popular vulnerability scanner with extensive vulnerability database

5. Common Vulnerabilities
- Unpatched software with known vulnerabilities
- System and network misconfigurations
- Weak passwords and inadequate access controls
- Vulnerable APIs with poor security
- Code injection flaws (SQL injection, XSS)
- Zero-day vulnerabilities
- Remote code execution vulnerabilities
- Insecure data storage and transmission

6. Types of Assessment
- Network-based assessment
- Host-based assessment  
- Application assessment
- Wireless network assessment
- Database assessment
- Cloud vulnerability assessment

7. Assessment Process
1. Asset Discovery - Identify all systems and devices
2. Vulnerability Scanning - Scan for known vulnerabilities
3. Analysis & Prioritization - Review findings and rank by risk
4. Reporting - Document vulnerabilities and recommendations
5. Remediation - Fix identified vulnerabilities
